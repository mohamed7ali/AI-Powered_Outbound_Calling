# Arabic AI Outbound Follow-Up Platform — Presentation Runbook

## Current implementation status

The platform supports organization-scoped Arabic outbound follow-up calls, post-call outcome persistence, unresolved-call escalations, a human-agent knowledge assistant, organization-scoped documents, and FCR reporting. The current local validation suite contains the Vonage-first regression and contract tests described in the repository.

The retrieval pipeline is functional, but its current deterministic embedding provider is not suitable for meaningful semantic ranking. It can return weakly related sources with zero or low similarity scores. For the presentation, describe this as a development-mode limitation and focus on the tenant boundary, the Arabic answer generation, the call outcome workflow, and the escalation queue. A production deployment should re-ingest documents after switching to a quota-backed or production-quality embedding provider.

## Demonstration sequence

### 1. Start the API and Gradio workspace

In the Codespace, start the API:

```bash
source .venv/bin/activate
set -a
source .env
set +a
PYTHONPATH=src uvicorn outbound_ai.api.app:app --host 0.0.0.0 --port 8000
```

In a second terminal, start Gradio:

```bash
source .venv/bin/activate
set -a
source .env
set +a
PYTHONPATH=src python -m outbound_ai.ui.app
```

The API port must be public if invitation links or external webhook tests are demonstrated. The Gradio port must be reachable from the presenter’s browser.

### 2. Authenticate and select the organization

Log in with the platform administrator or organization member account. Select the intended organization from the organization dropdown. Organization selection is required for every tenant-scoped operation.

### 3. Upload an Arabic knowledge document

Open **المعرفة والمستندات**, upload an Arabic TXT, PDF, or DOCX file, and press **رفع ومعالجة المستند**. The document is stored in the private organization bucket and indexed with the organization identifier.

### 4. Demonstrate the human-agent assistant

Open **مكتب الموظف** and ask an Arabic question related to the uploaded document. The answer should be generated by Gemini when `LLM_PROVIDER=gemini` and the configured Gemini key is valid. The answer includes a source section when citations are returned. Do not claim that the deterministic similarity score is a reliable relevance score in this mode.

### 5. Create a follow-up task

Open **متابعة الحملات**, refresh the cases list, select a case, choose a scheduled time, and press **جدولة متابعة**. This creates a row in `public.follow_up_tasks` scoped to the active organization.

### 6. Dispatch a simulated call

Run one scheduler cycle:

```bash
source .venv/bin/activate
set -a
source .env
set +a
PYTHONPATH=src python - <<'PY'
from outbound_ai.telephony.scheduler import run_follow_up_cycle
print(run_follow_up_cycle(limit=20))
PY
```

With `TELEPHONY_PROVIDER=simulated`, the result should show a dispatched call and a call row in `public.calls`. The task remains in progress until a terminal outcome is supplied; this mirrors real Vonage behavior, where provider acceptance is not the same as customer resolution.
 No real telephone call is placed in simulated mode.

To complete the simulated call without editing the database manually, call the guarded development endpoint with the authenticated agent token and organization ID:

```bash
curl -X POST "$API_BASE_URL/campaign/calls/<CALL_ID>/simulate-outcome" \\
  -H "Authorization: Bearer $ACCESS_TOKEN" \\
  -H "X-Organization-Id: $ORGANIZATION_ID" \\
  -H "Content-Type: application/json" \\
  -d '{"outcome":"ANSWERED_RESOLVED"}'
```

Use `ESCALATED` to place the call in the human-agent queue, or `NO_ANSWER` to demonstrate retry/backoff. This endpoint is available only in development and is not used for live Vonage calls.

### 7. Demonstrate an unresolved outcome

For a Vonage or simulated call demonstration, use an Arabic unresolved response such as:

```text
لسه المشكلة موجودة
```

The routing policy records the call as escalated and inserts a pending row in `public.escalations`. The call ends without a live transfer.

### 8. Open the human escalation queue

Return to **مكتب الموظف** and press **تحديث التصعيدات**. The queue now displays the customer, case subject, escalation reason, latest customer message, timestamp, and escalation identifier. The human agent can use the RAG assistant to investigate the case and then mark the escalation as handled.

### 9. Generate the FCR report

Open **تقارير الجودة**, enter a date range containing the call, and press **إنشاء تقرير FCR**. The report aggregates only the active organization’s calls and returns total calls, answer rate, first-contact resolution rate, escalated calls, average duration, and Arabic report text.

## Live Supabase validation checks

Run these queries in the Supabase SQL Editor after the demo. Use the actual organization UUIDs from the platform.

```sql
select id, organization_id, provider, status, outcome, created_at
from public.calls
order by created_at desc
limit 20;
```

```sql
select id, organization_id, call_id, reason, status, assigned_human_id, created_at
from public.escalations
order by created_at desc
limit 20;
```

```sql
select id, organization_id, title, status, created_at
from public.knowledge_documents
order by created_at desc
limit 20;
```

The tenant-isolation demonstration requires two organizations and two members. Sign in as an agent from organization B, select organization B, and verify that organization A’s cases, documents, calls, and escalations do not appear. A direct SQL or API request that supplies organization A’s identifier must also be rejected unless the authenticated actor is authorized for organization A.

## Environment modes

| Capability | Presentation mode | Production prerequisite |
|---|---|---|
| Outbound calling | `TELEPHONY_PROVIDER=simulated` | Vonage Voice Application, supported virtual number, public HTTPS webhooks, key pair, and callback verification testing |
| Arabic answer generation | Gemini configured | Stable model name, quota, request limits, and monitoring |
| Semantic citation ranking | Deterministic development embeddings | Production embedding provider followed by document re-ingestion |
| Invitations | Supabase built-in email service | Custom SMTP provider for dependable onboarding volume |
| Deployment | Codespaces | Persistent host, TLS termination, secrets management, worker supervision, and backups |

## Important presentation wording

Say that the platform follows a **post-call escalation model**, not a live-transfer model: the AI completes the outbound check, records the result, ends the call, and leaves an actionable human queue when the problem remains unresolved. The human agent then uses the organization’s private knowledge base to investigate and resolve the case.
